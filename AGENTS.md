# kf-stack agent guide

This repository holds portable instructions and skills. Keep changes small and grounded in observed preferences.

- Read [docs/preferences.md](docs/preferences.md) before changing shared conventions.
- Keep unresolved choices in [docs/pending.md](docs/pending.md).
- Keep project facts and commands in each target project's AGENTS file.
- Use [review-change](review-change/SKILL.md) for requested reviews and [verify-app](verify-app/SKILL.md) for application verification. This repository itself has no application runtime.
- For documentation changes, inspect relative links, code fences, examples, and the diff. Validate skill frontmatter and referenced resources when skills change.
- Keep commits focused and use a short subject. If a body helps, use at most 4–5 bullets, each 1–2 sentences.
- PR descriptions contain only a `# Summary` section with at most 7–8 bullets, each 1–2 sentences. Include relevant validation and risks there.
- Report the delivered artifacts, checks actually performed, and remaining gaps.
